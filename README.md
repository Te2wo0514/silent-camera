# 無音カメラ（Webアプリ）

iPhone・Androidのブラウザで動く、シャッター音のないカメラです。カメラ映像のフレームを切り出して保存するので、音は鳴りません。インストール不要・無料で、撮影データは端末の外に送信されません。

## 使い方
1. iPhoneはSafari、AndroidはChromeでこのページのURL（GitHub Pages）を開く
   - LINEなどのアプリ内ブラウザでは動かないことがあります（LINEからは自動で外部ブラウザに切り替えます）
2. ホーム画面に追加する（iPhone：共有ボタン →「ホーム画面に追加」／Android：メニュー →「ホーム画面に追加」）
3. ホーム画面のアイコンから起動 →「カメラを起動」→ カメラと位置情報を許可

## 機能
### 撮影
- 写真：4:3 / 16:9 / 1:1、タイマー（3秒・10秒）、長押しで連写、フィルタ（10種）、グリッド、水平器
- タップでピント合わせ、ピント枠の上下ドラッグで明るさ調整（純正カメラと同じ操作）
- レンズ：0.5×（超広角）/ 1× / 2× / 望遠（ブラウザから使えるもの）、ピンチでズーム
- フラッシュ：背面はライト点灯、前面は画面フラッシュ（ライトを操作できない端末ではボタンを自動で非表示）
- 横持ち：画面の配置は縦のまま固定し、映像と倍率表示だけ回転（写真・動画は横長で保存）
- ビデオ：1080p / 4K、30 / 60fps、音声あり・なし、一時停止・再開（開始音・終了音なし）
  - 対応端末ではHEVC、非対応ならH.264で記録

### 保存・ギャラリー
- 保存方法：ギャラリーにためて後でまとめて保存（既定）／撮影ごとに保存
- 保存先：iPhoneは共有メニュー経由で写真アプリへ、Androidは端末の「Download」フォルダへ
- 写真アプリへ保存したものは、アプリ内から自動で削除（設定でオフ可）
- ギャラリー：写真を開いて左右スワイプで前後に移動、選択ボタンで複数枚をまとめて保存・削除、削除後は隣の写真を表示
- 左下のサムネイルを長押しで、直前に撮った写真をその場で確認
- 位置情報・撮影日時：JPEGのEXIFに書き込み（写真アプリの地図・日時に反映）
- 画質：JPEG 95%（既定）／100%／90%／PNG
- ブラウザに保存データの保護を申請し、容量不足時の自動削除を防ぐ

### その他
- 検索エンジンには表示されない設定（noindex）
- 設定 →「情報」で、アプリの版や端末の対応状況（ピント・明るさ・ライト・録画形式など）を確認可能

## 制約（Webアプリのため）
- 写真アプリへの保存は共有メニューの「画像を保存」/「ビデオを保存」を経由します（直接保存は不可）
- ナイトモード、HDR、ポートレート、Live Photos、HEIC形式は使えません
- 音量ボタンをシャッターとして使うことはできません
- カメラを起動すると、ほかのアプリで再生中の音声や動画が止まる場合があります（iOSの制約）
- iPhoneのブラウザはピント位置の指定に対応していないため、明るさは画像補正（写真のみ）で調整します
- Androidの多くの機種では、ブラウザから使えるのはメインの背面カメラのみです（超広角・望遠は不可）
- ビデオには位置情報が付きません。PNGで保存した場合も位置情報は付きません
- 横持ちにすると一瞬ブラウザの回転アニメーションが見えます。画面の縦向きロック中やAndroidのホーム画面アプリでは、横長での保存になりません

## 更新が反映されないとき
アプリを完全に終了してから開き直してください。設定 →「情報」の「アプリ版」で、いまの版を確認できます。

他人を無断で撮影しないでください。
