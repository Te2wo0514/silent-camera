# 無音カメラ（Webアプリ）

iPhoneのSafariで動く、シャッター音のないカメラです。カメラ映像のフレームを切り出して保存するので、音は鳴りません。

## 使い方
1. SafariでこのページのURL（GitHub Pages）を開く
2. 共有ボタン → 「ホーム画面に追加」
3. ホーム画面のアイコンから起動 → 「カメラを起動」 → カメラと位置情報を許可

## 機能
- 写真：4:3 / 16:9 / 1:1、タイマー（3秒・10秒）、長押しで連写、フィルタ（10種）、グリッド、水平器
- レンズ：0.5×（超広角）/ 1× / 2× / 望遠（端末にあるもの）、ピンチでズーム
- フラッシュ：背面はライト点灯、前面は画面フラッシュ
- ビデオ：1080p / 4K、30 / 60fps、音声あり・なし（開始音・終了音なし）
- 保存：撮影ごとに共有シートを開く、またはギャラリーにためて後でまとめて保存
- 位置情報・撮影日時：JPEGのEXIFに書き込み（写真アプリの地図・日時に反映）

## 制約（Webアプリのため）
- 写真アプリへの保存は、共有シートの「画像を保存」/「ビデオを保存」を経由します
- ナイトモード、HDR、ポートレート、Live Photos、HEIFは使えません
- ビデオには位置情報が付きません。PNGで保存した場合も位置情報は付きません
- 音量ボタンをシャッターとして使うことはできません

他人を無断で撮影しないでください。
